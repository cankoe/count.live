Recurring Countdowns

Use recur to auto-reset the countdown. When the countdown reaches zero, it calculates the next occurrence and continues unless a top-level redirect is configured.

Multiple Countdowns

Use multi=1 with numbered parameters such as date1, title1, end1, date2, title2, end2, etc. Shared units, bg, fg, and font settings apply to the whole multi view. Up to 5 countdowns are supported.

Progress Tracking

Use progress=1 and/or percent=1 with a start date to show a visual progress bar and percentage completion.

Embedding

count.live countdowns can be embedded on any website or platform that supports iframes or rich embeds.

Embed in Canva

  1. Create your countdown on count.live and copy the URL
  2. In Canva, add an Embed element (Apps > Embeds or type /embed)
  3. Paste the countdown URL
  4. Canva auto-detects the embed and shows a live countdown

Tip: Add &embed=1 to the URL for a cleaner look without corner buttons.

Embed in Notion

  1. Create your countdown on count.live and copy the URL
  2. In Notion, type /embed or paste the URL directly
  3. Choose "Create embed" when prompted
  4. Resize the block to fit your layout

Tip: The countdown is fully interactive — visitors see it count down in real time.

Custom website (iframe)

Use the Embed button in the builder to get ready-to-use iframe code, or add embed=1 to any countdown URL for minimal UI:

<iframe src="https://count.live/?date=2027-01-01T00:00:00&title=New%20Year&embed=1"
  width="400" height="200" frameborder="0"
  style="border:none;"></iframe>

Tips

  • embed=1 hides the corner buttons and promo badge for a clean look
  • Visual customization parameters (theme, font, colors, background image, etc.) work in embedded mode
  • The embed is fully responsive — it adapts to whatever size you give the iframe
  • Post-end redirects are disabled when the countdown is embedded

Date Formats

The following date formats are supported. Examples without an explicit timezone are interpreted as UTC:

  • 2025-12-31T23:59:59 - Full date and time
  • 2025-12-31T23:59 - Date and time without seconds
  • 2025-12-31 - Date only (midnight)

How Units Work

The largest selected unit shows the total value. Smaller units show the remainder after subtracting larger units.

Example: If you select weeks and minutes for a 15-day countdown, you'll see "2 Weeks, 1440 Minutes" (not "2 Weeks, 30 Minutes").

Clickable Links

URLs in the title, subtitle, and end message are automatically converted to clickable links. Just paste a full URL (starting with http:// or https://) and it will be linked.

When Does the Countdown End?

The countdown ends at the exact target time. Hidden smaller units are accounted for using ceiling logic.

Example: If you select only minutes for a countdown to 12:30:45, you'll see "1 minute" until 12:30:45, then "0 minutes" briefly, then the end message.

This ensures the countdown reaches zero only when the target time has truly arrived.

Precise Time Calculations

Years and months are calculated using actual calendar dates:

  • Years - Exact calendar years (accounts for leap years)
  • Months - Exact calendar months (accounts for varying month lengths)
  • Weeks/Days/Hours/etc. - Calculated from remaining time after years/months

Example: From Jan 15 to Mar 15 is exactly 2 months, regardless of whether February has 28 or 29 days.
